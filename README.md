## Reflection

This activity helped me understand how algorithmic problem-solving can be improved through careful selection of data structures and efficient algorithms. The five problems covered arrays, strings, dynamic data structures, comparison logic, and frequency counting. I learned that analyzing time and space complexity before implementation helps in choosing an appropriate solution. For example, using a hash map for Sparse Arrays allows the strings to be counted efficiently rather than repeatedly scanning the entire list for every query. The problems also provided practice in writing clean C++ solutions and testing them against different cases on HackerRank. Integrating the solutions into GitHub helped organize the work into a portfolio that can be reviewed easily. Overall, the activity strengthened my understanding of algorithmic optimization and showed how efficient solutions can reduce unnecessary computation while maintaining clear and readable code.
